# Noelle

> **AI-powered PR generation and MCP server tooling for developers.**

[thenoelle.app](https://thenoelle.app)

Noelle helps developers ship faster. Paste a GitHub repo URL, describe what you want changed, and Noelle generates a pull request — no setup, no configuration, no context switching. Noelle also generates ready-to-use MCP (Model Context Protocol) servers from any repo so your AI tools can talk directly to your code.

---

## What Noelle Does

- **Build with Noelle** — Describe a code change in plain English. Noelle opens a PR on your repo with the changes applied, build-validated, and review-ready.
- **MCP Server Generator** — Paste any GitHub repo URL and get a fully functional MCP server and Claude Desktop config in seconds, powered by [+12 Monkeys](https://plus12monkeys.com).
